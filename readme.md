# Learning C Programming from Scratch  

Welcome to this repository! This is my personal journey into mastering **C Programming** through structured learning, hands-on practice, and active note-taking. My goal is to build a strong foundation in C by understanding its core concepts and applying them through practical implementations.  

---

## 📚 Resources  

The learning in this repository is inspired by several key resources, but it is not limited to them:  

- **The C Programming Language** by Kernighan and Ritchie (K&R)  
- **MIT OpenCourseWare**: Practical Programming in C (6.087)  
- Online tutorials and documentation  

While these resources provide guidance, the focus is on **active learning**:  
- Writing code to implement key concepts.  
- Exploring additional topics using **search engines** and **LLMs** (Large Language Models) for better understanding.  

---

## 🛠️ Approach to Learning  

### Core Concepts First:  
I'll focus on understanding fundamental topics like variables, data types, control structures, and pointers before diving into advanced topics.  

### Hands-On Practice:  
Each concept is accompanied by practical examples and small exercises to reinforce understanding.  

### Active Note-Taking:  
Notes are taken in Markdown format (organized for clarity), and they are uploaded to this repository. These notes highlight key topics, but you are encouraged to explore further through books and online resources.  

### Projects for Deeper Understanding:  
Beyond exercises, I'll implement mini-projects that apply learned concepts to real-world problems, solidifying my knowledge of C.
